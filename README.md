# Unconsumed Games

Marketing site for [Unconsumed Games](https://unconsumedgames.com) and **Covenanter**, a story game set in the Scottish Reformation, 1559–1560.

## Pages

- `/` — studio home and launch list
- `/press` — press kit and brand downloads
- `/delete-account` — how to delete a Covenanter account
- `/privacy` — privacy notice

The launch-list form stores an email in the browser only. It does not send mail until a list service is connected.

## Develop

```bash
npm install
npm run dev
```
